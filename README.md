# 🎹 Code Piano — Turn Your Code Into Music

> An interactive web application that transforms source code and text into unique procedural generative music in real-time.

🔗 **[LIVE DEMO](https://iridescent-starburst-7d3c35.netlify.app/)**

---

## ⚡ Overview

**Code Piano** parses ASCII character codes, line lengths, and syntax structures to map them directly into synth notes, rhythms, and audio parameters. Paste any snippet of Python, JavaScript, C++, or plain text to hear what your algorithms sound like!

### ✨ Key Features
* 🎶 **Real-time Audio Synthesis:** Powered by `Tone.js` and Web Audio API.
* 🎼 **Dynamic Pitch Mapping:** Character ASCII codes determine note pitches and frequencies.
* 🥁 **Algorithmic Rhythm:** Line lengths and indentation shape tempo and delays.
* 🌈 **Canvas Visualizer:** Interactive audio equalizer animated using HTML5 Canvas.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Audio Engine:** [Tone.js](https://tonejs.github.io/)
* **Graphics:** HTML5 Canvas API
* **Deployment:** Netlify
